Desenvolvimento individual de uma aplicação de terminal em C++ para controle financeiro, funcional e em evolução.

O sistema permite cadastrar, consultar, editar e excluir entradas e saídas, com cálculo automático do saldo. Inclui histórico, busca e filtros por tipo, origem e valor, além de relatório com totais de entradas e saídas, saldo e quantidade de movimentações.

Os dados são armazenados em arquivo TXT e carregados automaticamente ao iniciar o programa. A aplicação inclui validação de entradas, tratamento de erros e verificação dos registros carregados do arquivo.

Foram utilizados structs, vectors, funções, referências, manipulação de strings e leitura e gravação de arquivos.

Atualmente, o projeto está na etapa de aprimoramento da robustez. As próximas etapas previstas são modularização do código, migração da persistência para MySQL e desenvolvimento de uma interface gráfica.
